# 🍌 孙割热点学.skill · 配置模板

> 使用方法：**复制本文件为 `config.md`**（和本文件放在一起），把示例值改成你自己的。
> **必填只有两项：`领域` 和 `资源`**。其他字段按需填，留空也能跑（skill 会用默认值或反问你）。
>
> 懒得手动填？把下面这句发给你的 AI：
> **"帮我在 config.md 里填好配置，我是做 XXX 的，主要在 XXX 平台，预算 XXX。"**
> 让它按你的情况直接生成。

---

## 空模板（复制这个填）

```yaml
名字: 
领域: 
平台: 
人设: 
资源: 
频率: 
风格: 
红线: 
目标: 
```

---

## 字段说明

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `名字` | 建议 | 生成文案语气用 | 小鹿 |
| `领域` | ✅ | 你做啥赛道，决定能接什么热点 | AI工具测评 |
| `平台` | 建议 | 主战场，决定文案形态 | 小红书图文 |
| `人设` | 建议 | 对外身份，用于反差设计 | 前大厂PM，现自由职业 |
| `资源` | ✅ | 单次能投入的钱/时间 | ≤1000元，每天1小时 |
| `频率` | 建议 | 更新节奏 | 周3更 |
| `风格` | 建议 | 正经/玩梗/毒舌/情感 | 玩梗为主 |
| `红线` | 建议 | 绝对不能碰的 | 不碰代孕、涉政 |
| `目标` | 可选 | 你自己盯上的热点 | 景甜事件 |
