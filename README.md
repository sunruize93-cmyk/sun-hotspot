## 它是怎么工作的？（30 秒看懂）

```
你填配置(领域/平台/预算)  →  skill 扫描当前热点  →  输出你的蹭热点作战包
[孙割热点学.skill]           [12层孙氏打法]          [选题+文案+风险]
```

**一个真实示例**（假设配置 = "AI工具测评 · 小红书 · 预算1000元"）：

> 📌 **热点扫描**：孙宇晨起诉景甜事件（8/27爆发，热度正高）→ 你的切入角度是"AI写作争议"，对应打法：锚定热点(#1)
>
> 🎯 **选题×3**：
> 1. 《孙宇晨万字长文，被蒸馏成15KB的AI skill》——AI+吃瓜双热点（数字轰炸法）
> 2. 《他问Claude该不该给5000万，AI说不要》——"Claude全责"梗（碰瓷造句法）
> 3. 《从新概念一等奖到法庭追债，同一个写作公式用了19年》——深度向（反转连续剧）
>
> ✍️ **主推选题文案骨架**：小红书图文 → 封面大字标题 + 3页图文卡 + 结尾互动钩子（完整版在输出里给）

看完这个示例，你就知道装了之后会得到什么了。

## 快速开始（5 分钟）

### 第 1 步：下载

```bash
git clone https://github.com/sunruize93-cmyk/sun-hotspot.git
```

### 第 2 步：生成你的配置

在 `配置模板/` 里找到 `config.example.md`，**复制一份改名为 `config.md`**：

```bash
cp 配置模板/config.example.md config.md
```

然后**只用填 2 个必填项**（其他都可以留空）：
- `领域`：你做啥的（例：AI工具测评 / 跨境电商 / 美食探店）
- `资源`：单次能投入多少钱/时间（例：≤1000元，每天1小时）

> 懒得手动填？直接把下面这句发给你的 AI：
> **"帮我在 config.md 里填好配置，我是做XXX的，主要在XXX平台，预算XXX。"**
> 它会把 `config.md` 按你情况填好。

### 第 3 步：启动

把你选好的 AI 工具打开，把 **`SKILL.md` 的全文**粘进去（当系统提示词），然后问它：

```
按我的 config.md 配置，扫一下今天有什么热点可蹭，给我出作战包。
```

如果用的是 Claude Code，装好技能后直接说 `/孙割热点学` 即可（安装见下文）。

## 完整使用指南

### 一、配置 config.md（每个字段什么意思）

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `名字` | 建议 | 生成文案语气用 | 小鹿 |
| `领域` | ✅ | 你做啥赛道，决定能接什么热点 | AI工具测评 |
| `平台` | 建议 | 主战场，决定文案形态 | 小红书图文 |
| `人设` | 建议 | 对外身份，用于反差设计 | 前大厂PM，现自由职业 |
| `资源` | ✅ | 单次能投入的钱/时间 | ≤1000元，每天1小时 |
| `频率` | 建议 | 更新节奏 | 周3更 |
| `风格` | 建议 | 正经/玩梗/毒舌/情感 | 玩梗为主 |
| `红线` | 建议 | 绝对不能碰的 | 不碰代孕、涉政 |
| `目标` | 可选 | 你自己盯上的热点 | 景甜事件 |

**没填的字段**，skill 会用默认值，或反问你 1-2 个关键问题补齐。核心就俩必填：**领域** + **资源**。

### 二、常用用法（Prompt 模板）

```text
# 热点扫描
按我的配置，扫一下今天有什么我能蹭的热点，用孙宇晨"24小时出手"的标准判断值不值得上。

# 选题生成
用孙氏公式给我出3个关于「XX」的选题，每个都要能溯源到他某次真实操作。

# 文案骨架
用"数字轰炸法"+"碰瓷造句法"，给我写一条蹭「XX热点」的小红书图文骨架，300字内。

# 复盘诊断
把我上一条爆款/扑街的帖子，用孙氏方法论做个复盘，指出我在哪一步丢了流量。
```

### 三、安装为 Claude Code 技能（可选，懂命令行再用）

```bash
# clone 之后，把整个文件夹放进 Claude Code 的技能目录
mkdir -p ~/.claude/skills && cp -r sun-hotspot ~/.claude/skills/孙割热点学
```

之后对话里输入 `/孙割热点学` 即可调用。

> **不想装技能？** 没关系。直接把 `SKILL.md` 全文 + 你的 `config.md` 内容一起贴进任何 AI 聊天工具（ChatGPT/Claude/Kimi/豆包都行），当系统提示词用，效果一样。

## 常见问题（FAQ）

| 问题 | 答案 |
|---|---|
| **我不会命令行，能用吗？** | 能。你只需要把 `SKILL.md` 贴给 AI + 填 config.md，全图形界面操作 |
| **AI 不按 skill 走怎么办？** | 把 `SKILL.md` 贴在最前面，并加一句"严格按上面的方法执行，每步都溯源到孙宇晨案例" |
| **蹭热点会不会翻车？** | 会。skill 自带风险提示和红线段，先读"🚨风险"再发。真出问题，用第9层"转移叙事框架"处理 |
| **我没有钱，能用"多少钱打法"吗？** | 能用。90%的打法是0成本（锚定热点/数字轰炸/制造对抗），钱只是加速器。见方法论里的资源适配表 |
| **热点都过去了才看到，还来得及吗？** | 用"三问"判断残值：热度还没退、你能插进极端变量、跟领域契合，就还能上 |
| **孙宇晨不是被SEC起诉过吗，学他不会出事吧？** | skill 已经把他的违法操作（洗售/操纵市场/雇名人隐瞒报酬）**剔除了**，只留合法内容营销打法。红线段也写了，按红线走 |

## 🚨 红线（必读）

1. 不造谣、不诽谤、不泄露隐私；涉及真实人物用事实并标注来源
2. 不诱导投资、不喊单、不刷量、不买粉、不操纵市场
3. 平台规则优先（小红书/抖音对代孕、涉政等话题敏感，以平台审核为准）
4. 流量有代价：蹭热点可能反噬，人设翻车是常态，想清楚再上
5. 理解不等于模仿：本技能用于理解流量逻辑，不构成对孙宇晨个人或其商业行为的背书
